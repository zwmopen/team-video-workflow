## 🚀 后续计划

### 📊 方案三：江湖工具箱深度 API 联动（中期计划）

**目标**：将江湖工具箱的采集能力深度整合为工作流的一部分，自动解析采集数据并为素材打上标签。

#### 阶段一：数据库解析

- [ ] 探索江湖工具箱 SQLite 数据库结构（位于 `D:\Program Files\江湖工具箱\MinApp\data\`）
- [ ] 解析 DY提取作品数据库，获取字段：作品ID、作者、标题、关键词、发布时间、点赞数、评论数
- [ ] 解析 XHS提取作品数据库，获取字段：作品ID、作者、标题、描述、话题标签、点赞数、收藏数
- [ ] 解析 KS提取作品数据库结构
- [ ] 解析 BiLi作品分析数据数据库结构

#### 阶段二：API 端点开发

- [ ] 添加 `/api/jianghu-extract` 端点：调用江湖工具箱工具并等待完成
- [ ] 添加 `/api/jianghu-parse` 端点：解析指定工具的数据库，提取作品元数据
- [ ] 添加 `/api/jianghu-import` 端点：将解析的元数据自动导入素材库标签系统
- [ ] 添加 `/api/jianghu-list-tools` 端点：列出所有可用的江湖工具箱工具及其状态

#### 阶段三：自动打标签

- [ ] 根据作品标题和描述自动提取关键词标签
- [ ] 根据作者信息自动添加创作者标签
- [ ] 根据点赞数/评论数自动添加热度标签
- [ ] 根据话题标签（如 #团建 #莫干山）自动添加地点/场景标签
- [ ] 建立文件名与数据库记录的映射关系

#### 阶段四：前端交互增强

- [ ] 在采集入库页面添加"一键采集并导入"按钮
- [ ] 添加采集进度实时显示
- [ ] 添加采集结果预览（显示新入库素材及其自动标签）
- [ ] 添加批量采集任务管理

#### 阶段五：自动化工作流

- [ ] 配置江湖工具箱下载路径自动指向待分类整理库
- [ ] 采集完成后自动触发数据库解析和标签导入
- [ ] 标签导入完成后自动刷新素材索引
- [ ] 添加定时采集任务（定时搜索指定关键词并入库）
