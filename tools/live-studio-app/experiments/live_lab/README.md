# 实况工坊 · 拼图与 AI 视频实验模块（2026-11-27）

状态：隔离实验，未接入正式 App，未发布。继续使用候选分支，不改 main，不触发本地电脑。参考项目 AIGC-LivePhoto-Maker 的模型提交/轮询思路；未复制其源码（根目录未发现 LICENSE）。现有共享 Android/iOS 实况封装保持原样。

## 实验能力与验证记录

- 四格独立轨迹：推近、左移、先推后拉、右移，曲线、振幅、启动时间不同，约 3.6%—5.2% 缩放。分格边界固定。
- 手动确认均分二宫格/四宫格。扁平图需要经人工核对的标题二值遮罩（白为保留），分格内小区域近似修补，重新叠回原始标题。无标题也需明确确认；不自动识别、不猜测文字背后的真实场景。现阶段不支持不规则宫格、复杂标题或独立原图层。注意拉远轨迹先轻推，保证首帧对齐。
- 云沙盒以用户提供的拼图和手工遮罩实际生成 1152x1536 / 30fps / 2s / 60 帧 MP4；人工查看末段帧，未发现明显标题重复，但不能保证遮罩修补无瑕疵。源素材与遮罩未上传仓库。
- 外部视频导入：以普通参考 MP4 实际生成 1080x1440 / 30fps / 1.5s / 45 帧，3s 请求对过短素材报错。尚未测试真实 Flow 下载视频、EXIF/旋转/HDR 的所有组合；视频与高清静态封面配对及原生封装留待接入现有引擎。
- 智谱适配：默认固定 cogvideox-flash，显式网络授权与额度核实后才提交，密钥仅从环境变量读取，无自动付费降级，无自动重提。SDK 请求/结果轮询使用注入模拟客户端；未调用真实模型、未验证真实账户额度与 SDK 字段兼容性，尚未实现结果下载。需下一步确认官方接口后做真实单样本验证；Google Flow 当前只支持手动下载视频后走通用导入，无自动化接入。
- 5/5 隔离 unittest 通过：四条轨迹和裁切边界、标题像素在编码前固定、错误布局/未确认遮罩拒绝、授权/固定模型、超时不重复提交。未执行正式仓库全套测试、手机构建、实机识别或发布。

## 本地复现（额度恢复后人工执行）

Python 3 + numpy + opencv-python-headless + FFmpeg/ffprobe；智谱真实调用才需 zhipuai。进入本目录：
```bash
python -m unittest -v
python live_lab.py input.jpg output.mp4 --rows 2 --cols 2 --mask title_mask.png
# 无标题且人工确认后：--confirm-no-title
```
遮罩与图像使用相同方向和尺寸，保留所有字及描边。输出文件已存在时拒绝覆盖。真实样本及参数请在本地复现，不上传用户图像。当前仅输出普通 MP4，不能把它称为已封装 Live Photo。
