# 素材投送中控 V1

把电脑上的多张图片或视频直接拖到某台安卓手机，手机收到后自动调起系统分享面板，可继续选择抖音、小红书等应用。

## 解决的步骤

旧流程：飞书上传 → 手机下载压缩包 → 解压 → 浏览器或文件管理全选 → 分享 → 删除临时文件。

新流程：电脑拖到设备卡片 → 手机收到 → 系统分享。

文案可由现有剪贴板同步，也可以在电脑面板填写；手机打开分享时会自动复制文案，并同时写入 `Intent.EXTRA_TEXT`。

## 当前 V1 能力

- 电脑网页中控显示在线安卓设备。
- 拖拽多张图片、多个视频到指定设备。
- 局域网直接传输，不经过飞书或外部云盘。
- 逐文件 SHA-256 校验，避免损坏文件进入发布流程。
- 手机前台时自动弹出安卓系统分享面板。
- 手机后台时显示“素材已接收”通知，点一下打开分享。
- 文件保存在 App 私有缓存，不进入相册和下载目录，不需要发布后手动删除。
- 可选文案同步到手机剪贴板。
- 同一台手机按批次串行接收，上一批未打开分享时不会被下一批覆盖。
- 在线服务使用 Android `connectedDevice` 类型，适合与电脑通过局域网保持持续连接。

## 电脑端启动

需要 Node.js 20 或更高版本，无需安装 npm 依赖。

Windows 双击：

```text
start-windows.cmd
```

或命令行：

```powershell
cd desktop
node server.mjs
```

打开：

```text
http://127.0.0.1:45832
```

面板会显示手机要填写的局域网地址和配对令牌。

## 安卓端安装

用 Android Studio 打开 `android/`，构建并安装 `app`。项目配置：

- `compileSdk = 36`
- `targetSdk = 36`
- `minSdk = 26`
- AGP `9.2.1`
- Gradle `9.4.1`
- JDK `17`

也可以从 GitHub Actions 的 `device-share-hub-debug-apk` 构建产物下载调试 APK。

首次打开后：

1. 手机和电脑连接同一 Wi‑Fi。
2. 从电脑面板复制“电脑地址”和“配对令牌”。
3. 给手机起一个容易识别的名称，例如“红米团建号01”。
4. 点击“保存并保持在线”。
5. 回到电脑面板，把图片或视频拖到这台手机卡片。

## 安卓系统限制

安卓 10 以后限制后台应用主动弹出 Activity。因此：

- 接收端 App 在前台：素材到达后可直接弹分享面板。
- 接收端 App 在后台：系统通知出现后，点击一次即可进入分享面板。

没有使用无障碍、Root 或模拟点击。

## Redmi / 小米建议

内部生产手机建议允许该 App：

- 通知权限；
- 后台运行；
- 自启动（系统提供时）；
- 电池策略设为“不限制”。

这只影响手机在线稳定性，不影响分享功能本身。

## 数据目录

电脑端默认写入：

```text
.device-share-data/
```

其中包含随机配对令牌、任务元数据和临时文件。不要提交该目录，也不要把端口暴露到公网。

## 测试

