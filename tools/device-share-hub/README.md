# 素材投送中控 V2｜零配置局域网版

把电脑上的多张图片或视频直接拖到某台安卓手机，手机收到后调起安卓系统分享面板，可继续选择抖音、小红书等应用。

## 使用体验

旧流程：飞书上传 → 手机下载压缩包 → 解压 → 浏览器或文件管理全选 → 分享 → 删除临时文件。

现在：

1. 手机安装并打开「素材投送」App。
2. Windows 双击 `素材投送中控.exe`。
3. 同一 Wi‑Fi 下的手机自动出现在面板中。
4. 把图片或视频拖到对应手机卡片。
5. 手机收到后直接打开系统分享；App 在后台时点一下通知。

**没有电脑地址、没有配对令牌、没有命令行、无需安装 Node.js。**

## 当前能力

- Windows 原生轻量面板，便携版双击运行。
- 自动发现同一局域网内已打开接收端的安卓设备。
- 多台手机在线时分别显示为设备卡片。
- 把多张图片或视频拖到指定卡片后直接传送。
- 可选文案随任务发送，手机打开分享时自动复制到剪贴板。
- 逐文件 SHA-256 校验。
- 手机前台时自动打开安卓系统分享面板。
- 手机后台时显示“素材已接收”通知，点一下打开分享。
- 文件只保存在 App 私有缓存，不进入相册或下载目录。
- 同一台手机一次只保留一批待分享素材，避免覆盖。
- 不使用无障碍、Root、模拟点击或外部云盘。

## Windows 端

下载 GitHub Actions 产物 `device-share-hub-windows-portable`，解压后双击：

```text
素材投送中控.exe
```

程序启动后会持续搜索同一 Wi‑Fi 中的接收端。Windows 防火墙若首次询问，请允许“专用网络”。

源码位于：

```text
windows-native/
```

这是纯 Win32 C++ 程序，不依赖 .NET、Node.js、Python 或浏览器。

## 安卓端

下载 GitHub Actions 产物 `device-share-hub-debug-apk` 并安装。首次打开后，接收服务会自动开启。

你只需要按账号用途修改设备名称，例如：

```text
红米团建号01
红米团建号02
旅游号手机
```

项目配置：

- `compileSdk = 36`
- `targetSdk = 36`
- `minSdk = 26`
- AGP `9.2.1`
- Gradle `9.4.1`
- JDK `17`

## 安卓系统限制

Android 10 以后限制后台应用主动弹出界面：

- 接收端 App 在前台：素材到达后直接打开分享面板。
- 接收端 App 在后台：显示通知，点一下进入分享面板。

小米/红米生产手机建议允许：

- 通知；
- 自启动；
- 后台运行；
- 电池策略“不限制”。

## 局域网安全边界

V2 按你的要求不做配对：同一局域网内运行兼容中控的电脑可以向接收端投送素材。因此只在可信任的家庭或办公 Wi‑Fi 中使用，不要在酒店、商场等公共 Wi‑Fi 开启接收。

## 远程在线版

协议已固定设备 ID，后续可增加云端中继：

- 同一 Wi‑Fi：继续局域网直传，速度最快。
- 手机使用流量或异地 Wi‑Fi：电脑与手机都主动连接云端通道，面板仍显示在线。
- 拖动操作不变，系统自动选择“局域网直传”或“云端中继”。
- 第一次在同一局域网出现时可自动绑定到同一工作区，不需要手输配对码。

建议方案见 `docs/REMOTE_CHANNEL.md`。
