# iOS 变更记录

## 0.6.16 - 2026-08-20

- 检查到新版本时，提示改为引导打开 AltStore 的 My Apps 更新，不再只提示连接电脑。
- 增加“复制更新源”操作，方便重新添加或恢复 AltStore 更新源。
- 版本升级为 0.6.16/build 35；需以云端 IPA 结构、版本和 SHA-256 校验为准。

## 0.6.14 - 2026-08-20

- 顶部分类筛选从“转化帖”统一显示为“精准流量”，泛流量筛选也统一去掉“帖”后缀；内部分类字段和目录识别保持不变。
- 版本升级为 0.6.14/build 33；需以云端 IPA 结构、版本和 SHA-256 校验为准。

## 0.6.13 - 2026-08-20

- 点击“发抖音”或“发小红书”后，对应按钮立即变为灰色；灰色仍可再次点击，不代表按钮被禁用。
- 作品卡片按平台分享次数恢复各自按钮状态；分享准备失败时会回滚即时灰色状态。
- 版本升级为 0.6.13/build 32；需以云端 IPA 结构、版本和 SHA-256 校验为准。

## 0.6.12 - 2026-08-19

- 作品卡片的“预览 / 发抖音 / 发小红书”改为左对齐的纵向紧凑按钮，按钮宽度按文案自适应，预览使用描边样式。
- 版本升级为 0.6.12/build 31；需以云端 IPA 结构、版本和 SHA-256 校验为准。

## 0.6.11 - 2026-08-18

- 删除 `ClipboardBridge`、剪切板自动监听/同步、`/v2/clipboard` 接收接口和设置开关；主动复制文案与诊断信息仍保留。
- 作品卡片改为一行“预览 / 发抖音 / 发小红书”三个紧凑按钮；作品详情图片预览支持左右滑动并显示张数。
- 版本升级为 0.6.11/build 30；需以云端 IPA 结构、版本和 SHA-256 校验为准。

## 0.6.10 - 2026-08-18

- 移除自动识别新截图、截图自动发送和截图主设备设置，不再申请相册读取权限。
- 删除截图接收开关和相关前台轮询；普通文件、图片导入、局域网收发与系统分享保持不变。
- 版本升级为 0.6.10/build 29；云端 IPA 会重新执行结构、版本和 SHA-256 校验。

## 0.6.9 - 2026-08-18

- iPhone `/v2/info` 新增 `workCounts`：总数、精准流量（`conversion`）、泛流量（`traffic`）和未分类库存与 Android/Windows 使用同一口径。
- 电脑自动补货只读取 `conversion` 精准流量库存；分类字段缺失时按未知处理，不再用总数猜测。
- 版本升级为 0.6.9/build 28；本地 Windows 环境未执行 Xcode 真机构建。
- 云端 IPA 打包与校验改为读取 `project.yml` 版本，不再固定使用上一版 0.6.8/build 27 的文件名和断言。

## 0.6.8 - 2026-08-08

- 设置、回收站等二级页面的导航返回按钮统一显示中文“返回”，不再出现英文 `Back`。
- 保持 `com.zwm.album`、现有作品数据、目录授权和设置不变，覆盖安装不会主动清空数据。
- 版本升级为 0.6.8/build 27；本轮不引入完整语言包。

## 0.5.3 - 2026-07-31

- 应用前台读取本机系统剪切板，并把最新一条同步给局域网可信设备；收到远端内容后写入 iPhone 剪切板。使用消息 ID、来源和跳数去重，避免多机循环。
- V2 接收服务支持可选中转元数据和一小时队列。当前设备不是最终目标时保存完整任务，前台选择直连目标或下一台设备继续转发；下游接收后删除本机副本。
- 设置增加“允许作为主设备接收”；关闭后拒绝自动截图任务。iPhone 离开前台不承诺持续接收，队列保留到重新进入应用或一小时过期。
- 版本升级为 0.5.3/build 22，继续保持 `com.zwm.album` 和 iOS 12 最低系统；覆盖安装不重置作品、目录授权和设置。

## 0.4.3 - 2026-07-20

- iPhone 6 固定作品库增加“导入文件或 ZIP”入口，空作品页和设置页都可进入；
- 多选图片与 TXT 时自动归入同一导入作品文件夹，导入后立即递归扫描；
- ZIP 解压新增标准 Deflate 支持，不再只支持电脑生成的存储式 ZIP；
- 较新 iPhone 继续保留选择外部作品总文件夹和切换固定目录，目录授权与旧作品状态不迁移、不清空。

## 0.4.2 - 2026-07-19

- 设置页增加独立的“声音通知”和“震动提醒”开关，两项默认关闭，升级后也不会自动打开；
- 只有主动打开声音通知时才申请系统通知权限；关闭后仍保留应用内传输状态，不弹通知、不响铃；
- 震动可单独打开或关闭，用于接收开始、完成和失败反馈。

## 0.4.1 - 2026-07-19

- 主界面工具统一放到顶部，顺序为纸飞机、刷新、回收站、设置，并改用固定尺寸绘制图标；
- 首次未设置作品目录时主动提示选择，设置页增加检查版本更新和更完整的软件说明；
- iPhone 每 2 秒向全局地址和当前 Wi‑Fi 子网主动广播，设备有效期放宽到 15 秒；
- iPhone 在前台等待接收时保持屏幕唤醒，避免自动锁屏导致安卓或电脑连接超时；
- 接收开始、进度、成功和失败增加前台通知，诊断信息增加当前发现设备；
- 修复接收连接读取器提前释放，导致安卓或电脑连接 iPhone 后一直等待到超时；
- 继续保持离开 App 后停止接收，不申请后台常驻能力。

## 0.4.0 - 2026-07-19

- 右下角增加简洁传送按钮，进入后按“设备 → 文件/文件夹”完成传送；
- 自动显示同一 Wi‑Fi 内的 Windows、Android 和 iPhone；
- iPhone 可主动向电脑或另一台手机传送文件，并显示实际上传进度；
- iOS 13 及以上可传送完整文件夹，保留目录结构；iOS 12 保留文件与 ZIP 选择；
- 继续使用 HTTP V2、SHA-256、取消任务和安全路径展开，不增加 IP、配对码或后台常驻。

## 0.3.0 - 2026-07-19

- 加入与 Android 共用的局域网自动发现和 HTTP V2 接收协议；
- 设置页增加手机名称，电脑下一次刷新时显示新名称；
- 支持普通文件、ZIP 和 Windows 生成的文件夹包，文件内容采用流式落盘并校验 SHA-256；
- 只自动展开带内部标记的电脑文件夹包，用户自己的 ZIP 保持原文件，避免误解压；
- 增加路径越界、文件数量、大小、取消和接收目录不可用的明确错误；
- iPhone 应用仅在前台接收，符合 iOS 后台限制并降低后台占用；
- GitHub Actions 已完成 iPhoneOS 构建、IPA 打包和协议相关测试。

## 0.2.0 - 2026-07-19

- 同一安装包最低系统调整为 iOS 12，覆盖 iPhone 6，并继续兼容较新 iPhone；
- UI 从仅支持新系统的 SwiftUI 改为 UIKit，保留双列作品卡片、数字徽标、分享次数、回收站和设置；
- iOS 12 自动读取“我的 iPhone/相册”，iOS 13 及以上继续支持选择外部总文件夹；
- 所有系统版本统一递归扫描最多 8 层、1000 个目录；
- 回收站改为应用内返回导航，并增加会实际删除文件的“清空”操作；
- 刷新后显示“已刷新 · 数量”；增加递归扫描与隐藏/回收站排除测试。
