# iOS 变更记录

## 0.1.2 - 2026-07-19

- 忽略 `.Trash` 等隐藏系统目录，不再把它们计入作品扫描；
- 禁止把隐藏系统目录设置为作品总文件夹，并给出可执行的重新选择提示；
- 空列表显示可见目录、隐藏目录和作品识别摘要，明确提示“选高或选低了一层”；
- 开启 iOS 文件共享，方便把作品放入“我的 iPhone/相册”；
- 业务扫描修复已实现，等待实体 iPhone 重新安装验收。

## 0.1.1 - 2026-07-19

- 修复 IPA 内部 `.app` 目录和可执行文件使用中文名称，导致部分 Windows 侧载工具按错误 ZIP 编码解析并提示 `Invalid file`；
- 内部产物改为 `Album.app/Album`，桌面显示名称仍为“相册”；
- 增加实体 iPhone 安装诊断记录和 Windows 侧载排障手册；
- Sideloadly 0.60.0 已在实体 iPhone 完成签名安装；业务功能仍为“已实现未验收”。

## 0.1.0 - 2026-07-19

- 新增原生 SwiftUI“相册”客户端；
- 新增系统文件夹选择和持久目录书签；
- 新增两列作品卡片及图片 + TXT 作品判定；
- 新增 TXT 自动复制、多图片系统分享和打开分享次数；
- 新增次日回收、回收站恢复和 7 天保留；
- 新增设置、隐私说明、清晰错误提示和脱敏诊断信息；
- 新增统一应用图标；
- 新增 GitHub Actions macOS 编译和 AltStore IPA 打包；
- 新增快捷指令真机搭建与 iCloud 链接导出清单。

验收状态：GitHub Actions 云端构建通过；所有实体 iPhone 功能仍为“已实现未验收”。
