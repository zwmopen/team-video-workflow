# 相册投送 V0.3.1：图标与设备备注

日期：2026-07-18

## 本轮目标

- Windows 和 Android 都补上正式应用图标，避免继续使用系统默认图标。
- Windows 端支持给手机做本机备注，方便多台手机区分。
- 显示优先级遵循：电脑本机备注 > 手机端广播名称。

## 设计选择

图标采用“相册卡片 + 绿色投送箭头”的方向：看起来像相册工具，但不伪装系统相册包名，也不改变分享来源的真实应用身份。

Windows 端备注只保存在本机：

```text
%LOCALAPPDATA%/ZwmDeviceShareHub/device-remarks.tsv
```

这样不会改手机端设置，也不会污染仓库。手机端自己设置的名称仍会通过局域网广播传给电脑；电脑端有备注时，卡片主标题显示备注，副标题保留手机名称、型号和 IP。
