# 相册投送 V0.3.1：图标与设备备注

日期：2026-07-18

## 本轮目标

- Windows 和 Android 都补上正式应用图标，避免继续使用系统默认图标。
- Windows 端支持给手机做本机备注，方便多台手机区分。
- 显示优先级遵循：电脑本机备注 > 手机端广播名称。

## 设计选择

图标采用“相册卡片 + 绿色投送箭头”的方向：看起来像相册工具，但不伪装系统相册包名，也不改变分享来源的真实应用身份。

Windows 端备注只保存在本机：

```text
%LOCALAPPDATA%/ZwmDeviceShareHub/device-remarks.tsv
```

这样不会改手机端设置，也不会污染仓库。手机端自己设置的名称仍会通过局域网广播传给电脑；电脑端有备注时，卡片主标题显示备注，副标题保留手机名称、型号和 IP。

## V0.3.3 补充：华为文件夹扫描兼容

华为 ELE-AL00 实体机上确认当前 0.3.2 已保存系统文件夹授权：

```text
content://com.android.providers.downloads.documents/tree/msd%3A519
```

0.3.2 日志显示它能识别并导入 1 个作品，但旧逻辑存在一个容易误判的问题：如果所选目录本身包含图片和 TXT，就会被当成一个作品并停止继续扫描，下面更多作品子文件夹可能不会显示。

0.3.3 改为：

- 递归优先：先扫描子文件夹。
- 如果子文件夹里没有作品，才把当前文件夹当成单个作品。
- 如果当前文件夹像“聚合目录”，并且子文件夹已经识别到作品，则跳过上层聚合目录，避免把一大坨内容合并成一个作品。
- 诊断日志增加 `scannedFolders` 和 `aggregateFolders`，方便定位是权限、格式、层级还是重复导入问题。
- 当没有识别到作品时，界面提示改为“没识别到作品：请选择包含‘图片 + TXT’的作品文件夹”。
