# LIVE 交互与引擎偏好：候选设计

日期 2026-11-27。源分支 feature/live-push-drift-20261127。未发布，不修改正式版本号。

## 产品规则

- 团队工作相册：点 LIVE 切换自动转换开关；长按约350ms展开紧凑菜单；手指不松开移动时预选，松开才提交，点击外部取消。静止长按保留菜单供点选；滑出取消不修改设置。第一位原推荐、第二位新复合运镜、第三位几乎静止；关闭另放末尾。
- 实况工坊：新增 LIVE 效果胶囊，点选/长按滑选；此候选保留显式存/分享实况语义，不偷换原图分享。设置的入口使用轻量菜单；质量/幅度等次级对话仍可保留，后续统一。
- 手机纯本地不自动识别拼图、不自动拆图、不跑 OCR。人工选择几乎静止适合拼图和文字密集图。独立分格实验不强制迁入手机。
- 动态处理偏好三种：智谱优先（默认的未来 AI 策略）、仅本地、Google Flow（待接入）。手机当前实际处理仍为本地；偏好只是保存策略，不上传照片。未来仅明确请求 AI 动态、获得上传授权、确认可用且预算/免费额度符合时调用对应引擎；不可用或失败按显式策略退回本地并报告，不自动转付费、不把失败说成 AI 成功。Google Flow 网页订阅不能假定等同 API；先验证官方接入或手动导入视频。
- 普通微动、几乎静止、已有 Live 直通不进入在线队列；手机现有封装/无损静态图不动。

## 视觉设计

参考 https://github.com/chen08209/FlClash/blob/main/.agents/surfaces.md 和 lib/pages/home.dart 的浮动表面、选中层、紧凑菜单和轻盈导航。保持原生 Java/UIKit，不复制外部代码。共用组件先试验 LIVE 菜单，再将已验证的设计推广到分段标签、底部工具栏、设置与弹层。iOS 使用系统材质；Android 首版用半透明表面、描边和缓动而非高耗电实时模糊。真实玻璃和全局主题尚未实现。保留系统返回、点击区、浅深色、动态字号与减少动效降级。
