# 设备与权限 · 分阶段候选

本分支新增本地 SQLite 授权记录、电脑端审批与权限分级面板、TLS-only 隔离服务候选。只用于独立测试库，尚未替换正式相册服务或发布安装包。安装客户端不等于授予工作区访问权。

## 试验边界

- 使用独立测试目录、独立数据库和测试 TLS 证书。测试客户端必须验证服务器证书（不能关闭验证），由电脑本机可信渠道分发证书/指纹。
- 电脑端启动 `python scripts/device_permissions_ui.py --db <测试数据库>`，局部审批、修改权限、撤销。手机侧未来需实现安全生成/保存独立凭证、证书验证、首次配对指纹展示和授权状态提示。
- 隔离服务：`python scripts/authorized_gallery_preview.py --root <测试作品库> --db <测试数据库> --cert <证书> --key <私钥>`。默认仅回环监听，远程测试另指定测试地址。不要使用业务目录、生产数据库或正式端口。
- 只读、运营、管理逐级授权。候选仅开放经过显式列举的接口，删除、剪贴板、远程登记以及其他未评审接口默认拒绝。永久删除保留本机确认。
- 本机审批面板不经网络管理 API，不信任设备名称、IP 或旧登记记录。撤销旧凭证后不得用同一凭证自动重新审批。
- 凭证摘要入库；不得上传数据库、证书私钥或凭证到仓库。

## 后续合并门禁

1. Windows 正式设置中增加「设备与权限」入口，并实现安全打包；Android/iOS 使用系统安全存储，完成证书信任、配对申请、授权状态、撤销处理；现有设备由管理员一次确认迁移，不根据旧记录自动提权。
2. LAN、USB、P2P、远程中继与在线目录使用同一权限语义；远程成员凭证及短时链接撤销机制需同步验证，隔离候选尚未接入这些通道。不能因 loopback 或局域网地址直接信任请求。
3. 所有副作用接口按资源、身份、动作检查权限，写操作审计与竞态、请求限速、凭证轮换、恢复机制需完成；禁止客户端任意声明身份。
4. 验证未知设备、待批准、只读越权、已撤销凭证、重新配对、重复请求、合法设备、并发与各网络通道。验证电脑/手机本地删除分离，保留原图和实况工作流。
5. 构建 Windows/Android/iOS 候选包并实机验收；尚未达到完整安全闭环前不得替换生产服务或自动发布。

自动测试：`python -m unittest discover -s scripts/tests -p test_device_authorization.py`（从 tools/device-share-hub 运行）。

## 2026-11-28 管理策略补充

- 已连接的本人设备优先平滑迁移：电脑端识别可信设备并允许管理员一次批量核对与授权，默认保留现有合法业务操作；未经认证的历史自动登记记录不能直接视为可信身份。
- 新设备默认拒绝，必须显式审批；批量审批前核对每台设备的独立指纹。
- 每台设备可单独更改权限、单独撤销，也可多选撤销或一键撤销全部（含待审批）。撤销后的旧凭证不可自动重新授权，重新连接需要新的配对凭证。
- 候选数据库实现了原子批量撤销和授权变更审计；当前不代表生产 Cloudflare/旧版手机会话已被同步吊销。
- 本轮首个 CI 中 Android、iOS、云端中继检查成功，Windows UTF-8 门禁失败；已修正候选界面脚本输出编码，并添加批量撤销持久化测试，待后续构建确认。
