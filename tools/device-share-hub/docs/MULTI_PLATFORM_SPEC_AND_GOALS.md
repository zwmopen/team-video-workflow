# 相册分发系统（Device Share Hub）多端统一产品设计手册与目标跟踪库

> **版本**：v0.7.1  
> **更新时间**：2026-09-01  
> **多端支持**：Windows 电脑端 / Android 手机端（全面屏+三大金刚键）/ iOS 苹果端（灵动岛+刘海+AltStore）

---

## 一、 📐 多端统一核心产品交互与视觉规范

### 1. 安卓端（Android）规范
1. **触摸屏第一交互**：
   - 全屏大图预览中，**左右横向滑动手势（Swipe / Fling）作为首要切图方式**；
   - 无论单指从左往右滑（上一张）还是从右往左滑（下一张），毫秒级平滑过渡，彻底免除强制点击小按钮的繁琐；
2. **多屏幕与导航栏自适应（防三大金刚键遮挡）**：
   - 全面兼容 Android 8.0 ~ Android 15+（API 26~36）；
   - 动态识别并计算虚拟/物理 **“三大金刚键导航栏”（高度通常为 48dp~56dp）** 与 **全面屏手势指示条**；
   - 底部控制栏与卡片操作按钮预留充足动态安全边距（`Math.max(28dp, navHeight + 14dp)`），**严禁任何按钮被底部按键栏遮挡、压底或挤压**；
3. **底部页码指示胶囊**：
   - 图片序号（如 `1 / 9`）统一置于 **屏幕底部正中央**；
   - 采用深黑半透明毛玻璃圆角胶囊设计（`rgba(30, 30, 30, 0.65)` + `18dp` 圆角），白字加粗居中，视觉纯净不抢画面；
4. **轻量与性能底线**：
   - 采用 `LruCache` 内存池 + `RGB_565` 异步并发解码；
   - Java 堆内存日常运行必须稳定控制在 **10MB ~ 15MB** 以内，快速滑动 60FPS 满帧无卡顿、0 崩溃。

---

### 2. 苹果端（iOS）规范
1. **安全区与异形屏自适应**：
   - 严格绑定 `safeAreaLayoutGuide.bottomAnchor`；
   - 适配灵动岛（Dynamic Island）、刘海屏以及底部 Home Indicator 安全边距；
2. **手势与预览交互**：
   - 采用横向 `isPagingEnabled = true` 原生滑动手势切图；
   - 序号胶囊统一置于底部安全区上方（`bottomAnchor - 24pt`），圆角 16pt；
3. **发布与分发流转**：
   - 一键直接发布（自动将文案塞入系统剪贴板并拉起系统分享面板）；
   - 兼容 AltStore 自定义源（`altstore.json`）一键静默/在线升级。

---

### 3. 电脑端（Windows）规范
1. **轻量化静默中控**：
   - 托盘常驻运行，开机自启；
   - 支持局域网 UDP 广播与 HTTP 流式直传；
2. **单作品闭环分发**：
   - 监听作品库 `已发送0次（抖音小红书可发）`；
   - 发现手机就绪即分发 1 套作品，收到接收端 ACK 确认后立即物理移动到 `已发送1次（微信公众号可发）` 归档。
