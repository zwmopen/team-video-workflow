# 小红书2｜高密度种草版公开模板

版本：2026-10-22.1

## 一句话识别

高密度种草版不是“更长的自然攻略”，而是：

**搜索型标题 + 情绪第一屏 + 参数卡 + 亮点速览 + 参考时间轴 + 玩法池 + 选择分流 + SEO 话题。**

## 标题

优先：
```text
{地点团建}｜{强玩法A}+{强玩法B}+{强玩法C}🍂
```

不只概括，要让人看到具体项目。

## 第一屏

3—5 行：
1. 季节/打工人/场景钩子
2. 为什么现在值得去
3. 一口气展示丰富玩法
4. 一句“可直接参考/抄作业”的结果感

## 参数卡

```text
📍 | 地点
⏰ | 时长
🙋‍♀️｜人数（有依据）
🚌 | 接送/交通（有依据或用户配置）
🎯 | 核心体验
```

## 亮点

每项写：
`项目名 + 具体画面/动作 + 为什么值得`

不是只写名词清单。

## 时间轴

如果只知道总时长，可以合理规划“参考时间轴”。

例如：
```text
🗓️ 1日行程参考
⠀
09:30｜集合 / 抵达
10:00｜核心项目A
11:30｜核心项目B
12:30｜午餐
14:00｜核心项目C
16:30｜慢体验 / 自由活动
18:00｜晚餐 / 烧烤
19:30｜返程 / 夜间活动
```

时间必须明确是参考安排，不能冒充官方开放时间。

## 玩法池

素材足够时保留 9—15 项真实可选玩法：

```text
🍁【可选玩法】
骑行🚴｜采摘🍊｜飞盘🥏｜露营🏕️
烧烤🔥｜手作🎨｜围炉🍵｜越野🚙
```

## 长度

素材足够时写到 900—980 字符，1000 内即可。

## 空行

只用 U+2800：
`⠀`

不要再用独立 `•` 叠加分隔。
