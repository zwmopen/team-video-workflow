# 团建双平台文案 Skill｜公开版

这是可直接分享给别人使用的 **公开精简版**。它把团建/周边游素材改写成 3 个默认版本：

1. **小红书1｜自然攻略版**：自然、顺口、信息完整，像成熟运营写的攻略笔记。
2. **小红书2｜高密度种草版**：更强标题、更高项目密度、参数卡、亮点、参考时间轴、玩法池、Emoji 与 SEO。
3. **抖音｜攻略版**：单独做更保守的平台表达处理，避免把小红书商业承接语气直接搬过去。

当前公开同步版本：**2026-10-22.1**

## 公开版与私有版

### 公开版
公开地址就是本目录。适合分享、复制、二次配置。

公开版包含：
- 三版本默认输出合同
- 小红书自然攻略规则
- 高密度种草模板
- 抖音保守改写规则
- 标题、排版、事实边界
- 参考时间轴规则
- 示例

公开版**不包含**：
- 私有业务资料、客户/项目记录
- 本地路径、账号、WorkId、生产队列
- 私有原始同行语料全文
- 内部自动化脚本、平台后台资料
- 仅用于本人业务的敏感配置

### 私有版
私有源仓库：`zwmopen/skills`（私有仓库，外部用户无法访问）。

私有版是完整生产真源，包含更多参考语料、脚本、验证器、业务能力配置和本地/网页生产连接。

## 同步原则

**私有版是 Source of Truth，公开版是可分享镜像。**

当私有版出现会影响普通用户写作行为的更新时，应在同一轮同步公开版，例如：
- 默认输出版本数量/顺序
- 小红书/抖音平台规则
- 高密度种草模板
- 字数上限
- U+2800 排版规则
- 时间轴生成规则
- 标题与事实约束

只涉及私有生产、账号、客户、路径、内部业务数据的更新，不同步到公开版。

## 使用

最简单的用法：

1. 打开本目录的 `SKILL.md`
2. 把它作为自定义指令 / Skill / 项目说明交给你的 AI
3. 再把团建素材、原文、路线或项目清单发给它
4. 默认会输出三版文案

也可以把整个 `teambuilding-copywriter-public` 文件夹复制到支持 Skill 目录的 AI 编程工具中使用。
