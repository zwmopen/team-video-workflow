# 团建文案三版生成 Skill（公开版）

一个用于团建 / 周边游 / 企业活动素材改写的公开版 Skill。

默认输出 3 个版本：

1. **小红书1｜自然攻略版**
2. **小红书2｜高密度种草版**
3. **抖音｜攻略版（安全 / 弱营销）**

## 怎么用

把 `SKILL.md` 作为项目指令 / Skill 指令使用，然后直接粘贴：
- 原始文案
- 路线
- 活动项目
- 图片里提取出的文字
- 目的地资料

如果没有额外要求，默认直接输出三版，不先做长篇分析。

## 这个公开版保留了什么

- 三版默认输出合同
- 小红书自然攻略写法
- 小红书高密度种草模板
- 高密度版参考时间轴规则
- U+2800 手机复制空行
- 标题钩子规则
- 事实防编造规则
- 抖音单独安全处理
- 900—1000 字高密度长度口径
- 大合集 / 单目的地的不同处理思路

## 和私有生产版的区别

公开版不包含：
- 私有客户 / 公司信息
- 私有素材库
- 私有历史成稿
- 内部 WorkId / 自动化 / 产线脚本
- 私有平台账号数据
- 私有业务能力默认值

所以它可以直接分享给别人使用，不会带出原项目里的内部信息。

## 文件

- `SKILL.md`：主指令
- `references/high-density-template.md`：高密度种草模板
- `references/platform-rules.md`：平台与事实边界

## 使用提示

如果你的业务有固定能力，例如“10人起”“可安排大巴”“可包院”“可定制”，请自行追加到 Skill 的【长期业务能力】部分；公开版不会默认替你写死这些事实。
