# 平台与事实规则

## 小红书

目标：丰富、可搜、可收藏、可决策。

允许正常出现：
- 团建
- HR
- 行政
- 公司团建
- 团建方案
- 一日 / 两日玩法
- 路线参考
- 真实人数 / 交通 / 服务能力（前提是当前使用者已经确认）

小红书不需要因为抖音的表达风险而主动删成“纯生活方式稿”。

## 抖音

默认采用更克制的表达。

单目的地：
- 普通用户视角
- 弱化服务承接
- 不写价格、套餐、预约、私信、下单、强获客 CTA
- 团建 / HR / 人数承接等词默认弱化

多目的地大合集：
- 可以按实际内容保留团建搜索词
- 但不叠加强商业承接信号

## 事实底线

平台不同，不代表事实底线不同。

所有版本都不能无依据补：
- 价格
- 车程
- 容量
- 营业时间
- 客户案例
- 评价
- 固定包含项
- 项目开放状态

## 长期业务能力

如果使用者自己的业务长期具备某能力，例如：
- 可安排大巴
- 10人起
- 可包院
- 可做1—3日
- 可定制

请在自己的私有版本里明确写入。

公开版不会替所有使用者默认这些事实。
