# 工作流上帝视角检查 2026-07-03

## 目标重新对齐

最终目标不是做一个完整剪映，而是做一条低参与度的短视频生产线：

1. 用户把新素材放进素材库。
2. 工具一键清洗、分镜、分类、提取音频和文案。
3. 用户选择一条音频或文案。
4. 系统按时间戳文案识别关键词，匹配对应画面素材。
5. 生成可预览、可微调、可导出的粗剪成片。

## 横屏素材选择规则

不再使用“一刀切横屏都是垃圾”的说法，改为三层：

1. 竖屏主素材：进入 `*智能镜头分类`，作为默认可剪素材。
2. 横屏原片候选：内容有价值的横屏原片保留，进入深度修复/备用队列。
3. 横屏分镜废料：已经裁剪成小画面、黑边明显、塞进竖屏分镜库的横屏分镜，移出主库。

例子：

- 千岛湖啤酒小镇原片有价值，保留在原片素材里，不删除。
- 莫干山庾村小镇横屏分镜已经是小画面产物，不再放在智能分镜主库。

## 已修复的问题

1. 缩略图旧缓存：
   - 旧逻辑只按素材 ID 缓存封面。
   - 新逻辑按源文件修改时间刷新封面 URL，并在源文件更新后重建缩略图。

2. 批量裁切范围：
   - 旧逻辑默认处理所有分镜素材。
   - 新逻辑只处理当前中间列表可见的素材 ID。

3. 批量处理入口重复：
   - 移除重复的文案/音频处理卡。
   - 移除“只提取音频”按钮。
   - 保留“提取音频/文案素材 -> 展开处理”。

4. 音频素材计数：
   - 旧逻辑把历史 `千岛湖音频素材库` 混入主工作流。
   - 新逻辑只展示 canonical `已整理原片音频`。

## 智能剪辑界面方向

智能剪辑界面应采用“轻量剪辑台”：

- 左侧：音频素材列表和搜索。
- 中上：候选片段素材架。
- 中间：3:4 或 9:16 预览画布。
- 下方：字幕轨、主视频轨、音频轨。
- 右上：导出按钮。

点击“开始匹配素材”后：

1. 读取音频同名时间戳文案。
2. 将台词切成 beat。
3. 从每句台词提取关键词。
4. 根据地点、关键词、分类、素材时长匹配 1-3 个画面。
5. 把字幕 beat 放到字幕轨，把视频片段放到主轨，把音频放到音频轨。
6. 预览时音频、字幕、画面同步播放。

## 开源参考

- OpenCut：完整开源剪辑软件方向，适合学习多轨时间线和插件架构。
- Cutia：本地优先、时间线、多轨、实时预览的浏览器剪辑器。
- Remotion：适合程序化视频生成、模板化渲染和自动化导出。

当前建议：

1. 本地浏览器工具继续做素材管理和轻量时间线。
2. 自动成片/导出优先走 Remotion 或 FFmpeg 渲染。
3. 不把当前工具膨胀成完整剪映；只做“选音频 -> 自动配镜 -> 可微调 -> 导出”的最短闭环。
