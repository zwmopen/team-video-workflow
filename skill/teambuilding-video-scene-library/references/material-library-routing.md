# 团建视频素材库路由

当前标准根目录：

`D:\Download\素材下载\团建视频`

## 固定入口

- `01_原片素材库`：已按地点归档的原始视频，作为重新提取音频、重新分镜、重新清洗的来源。
- `02_分镜素材库`：已切分、分类、清洗后的可剪辑分镜素材，剪辑优先用这里。
- `03_音频文案库`：原片音频、时间戳文案、纯文案、ASR 结果。不要再套 `已整理原片音频` 或 `<地点>音频素材库` 外壳。
- `04_智能剪辑初剪库`：按音频/文案配镜后输出的初剪素材包、配镜表、预览视频、剪映草稿包。
- `90_待整理与记录`：待整理素材、模板、缓存、采集记录、删除记录、测试报告。

## 写入规则

1. 新采集但未整理的视频先进入 `90_待整理与记录\00-待分类整理库`。
2. 采集入库后，原片移动到 `01_原片素材库\<地点>-原视频素材`。
3. 分镜和清洗后的素材进入 `02_分镜素材库\<地点>智能镜头分类`。
4. 音频和文案进入 `03_音频文案库`，可按地点建子文件夹，也允许历史散音频留在根目录。
5. 文案配镜/初剪输出进入 `04_智能剪辑初剪库\<日期时间_任务标题>`。
6. 缓存、浏览器标签、删除记录、批处理报告进入 `90_待整理与记录`。
7. 旧扁平目录只作为读取兼容兜底，不再作为新输出位置。

## 交接提示

其他 AI 或本地工具接手时，先读取：

- `D:\Download\素材下载\团建视频\素材库路由说明.md`
- `D:\Download\素材下载\团建视频\素材库路由表.json`

然后按固定入口执行，不要在根目录新增散乱工程文件夹。
