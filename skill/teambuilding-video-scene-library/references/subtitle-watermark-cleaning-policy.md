# 字幕水印清洗策略

本文件记录 2026-07-01 的素材清洗结论。目标是把素材变成剪辑可复用的“真干净素材”，不是简单裁剪，也不是把画面修坏后继续入库。

## 结论

1. “去字幕水印”和“裁掉底部”不是一回事。裁剪只能作为临时替代方案，不能命名为最终干净库。
2. 批量清洗前必须先做 `audit-overlays`，抽关键帧识别底部字幕、顶部水印、中部贴字、大字海报和黑边贴片。
3. 机器初筛为 `clean` 的片段可以复制到“无字幕水印干净候选库”。
4. `bottom_subtitle` 才适合优先进入 VSR / ProPainter / LAMA 等深度去字幕流程。
5. `top_watermark`、`center_overlay`、`mixed_overlay` 不允许直接批量硬抹；必须先做小样对比。修复后如果天空、脸、手、食物、项目动作变糊或变块，就不要入库。
6. 半透明地点水印，例如画面中部/上部的“千岛湖”，当前 OpenCV 快速修复不合格；宁可标记为待深度修复或找替代素材，也不要产出劣质修复。
7. 清洗后必须保持原视频尺寸，除非用户明确接受裁剪版。
8. 正式交付前必须二次审计，确认输出库 `dirty=0` 或明确列出仍需修复的片段。
9. 中间大字、贴纸、标题卡、图文海报类片段不是清洗对象。分镜后发现这类片段，应直接移出可用素材库，放入废料/待复核记录，不进入剪辑素材关键词文件夹。

## 开源工具定位

- VSR / VideoSubtitleRemover：适合普通硬字幕、规则文字区域；CPU 很慢，大批量前必须小样验证。
- ProPainter / LAMA：适合更强的视频修复，但需要更好的遮罩和 GPU/时间预算。
- OpenCV inpaint：只能做快速原型，不能作为最终画质标准。

## 工作流规则

1. 新素材先分镜分类。
2. 再跑字幕水印审计。
3. clean 片段复制进入无字幕水印候选库。
4. dirty 片段进入 `needs_deep_repair.csv`，按价值排序处理。
5. 深度修复后必须生成前后对比图，并再次跑 `audit-overlays`。
6. 二次审计不通过的片段不得混入干净库。
7. `center_overlay`、`mixed_overlay`、标题卡、封面页、图文讲解页默认作为废料片段剔除；只有用户明确要求保留时才进入待修复。
