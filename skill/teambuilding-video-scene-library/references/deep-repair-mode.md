# 深度修复模式

本文件记录素材清洗的第二条路线：在 `裁剪模式` 之外，使用 VSR / AI inpainting 去除硬字幕或水印文字。

## 两种清洗模式

1. `裁剪模式`
   识别字幕线、黑边、封面帧和标题废料，通过画面裁剪或时间切割生成可用素材。适合批量、速度快，但会改变画幅或丢掉部分画面。

2. `深度修复模式`
   使用 VSR / AI inpainting 保留原始画幅，尝试把硬字幕、水印文字从画面中修掉。适合珍贵画面、人物/项目动作/风景不能裁掉的片段。

## 默认决策

1. 能裁掉且不影响素材价值时，先走 `裁剪模式`。
2. 裁掉会损失人物、项目动作、食物、住宿空间、风景主体时，进入 `深度修复模式`。
3. 大标题、大贴纸、图文海报、封面废料仍然走 `裁切废料`，不走深度修复。
4. 深度修复必须先小样本测试，再批量。
5. 每次测试必须输出前后对比图。
6. 修复后若水面、天空、脸、手、食物、项目动作区域有明显涂抹痕迹，不得进入干净库。
7. 通过二次视觉复核后，才能标记为 `deep_repair_clean`。

## 2026-07-04 深度修复定位规则升级

深度修复不是“直接把整条视频交给工具就会自动干净”。它分两步：

1. 定位：判断字幕、水印、贴字到底在哪里，得到一个或多个修复框。
2. 修复：把修复框交给 VSR / AI inpainting 去补画面。

当前本地按钮只能做快速规则定位，适合固定底部字幕、固定顶部水印、同来源同版式素材。它不是完整视觉理解模型，不能保证识别所有位置的水印。

高精度工作流必须按下面顺序执行：

1. 从视频抽取 3-5 张代表帧，优先取 10%、35%、60%、85% 时间点。
2. Codex/视觉 AI 先看抽帧，判断是否存在底部硬字幕、顶部/角落/中部半透明水印、中间大标题、大贴纸、封面废料、黑边或平台水印。
3. 视觉 AI 输出修复区域，格式为：`x_min, y_min, x_max, y_max, reason, confidence`。
4. 只有 `confidence >= 0.75` 且画面主体不会被误伤时，才调用 VSR 深度修复。
5. 如果是大标题、大贴纸、封面废料，优先走 `裁切废料/时间切割`，不要深度修复。
6. 如果是小水印或硬字幕，优先走 `深度修复模式`，并生成前后对比图。
7. 修复后必须再次抽帧复核。水印仍可读、残留涂抹明显、天空/水面出现方块痕迹时，不进入干净库。

结论：VSR 是“修复执行器”，不是“视觉判断器”；本地启发式检测只能当快速辅助；真正可靠的深度修复 Skill 必须由 Codex/视觉 AI 先定位水印和字幕，再调用工具。

## 2026-07-04 千岛湖阿明淡水印测试结论

测试素材：

`D:\Download\素材下载\团建视频\千岛湖智能镜头分类\01_环境空镜\千岛湖风景\001_千岛湖_千岛湖风景__S_V003_S006.mp4`

关联同源分镜：

`__S_V003_S*.mp4`，共 19 条。

测试方式：

1. Codex 视觉定位水印区域。
2. VSR `sttn-auto` 按框修复。
3. OpenCV 区域修补。
4. OpenCV 文字遮罩修补。
5. 抽帧复核。

结果：

1. VSR 可以运行，但对“千岛湖阿明”这种低对比、半透明、天空背景水印去除不稳定，水印仍可读。
2. OpenCV 区域修补能弱化水印，但容易留下矩形天空补丁。
3. OpenCV 文字遮罩修补速度快，但在不同画面亮度下仍可能残留水印。
4. 本批 19 条同源分镜已生成测试副本和复核帧，但不能视为合格干净素材，不能自动替换原分镜。

新规则：

1. 低对比天空/水面半透明水印，不允许直接批量进入干净库。
2. 这类素材必须先输出测试副本和 before/after 抽帧。
3. 复核后仍可读、残影明显、天空出现块状补丁时，标记为 `深度修复不合格`。
4. 不合格时优先找替代素材；只有画面非常关键时，才保留修复副本作为备选。
5. 软件按钮不再直接启动本地深度修复，应改为 `复制提示词`，把当前素材路径和标准修复流程交给 Codex/视觉 AI 执行。
